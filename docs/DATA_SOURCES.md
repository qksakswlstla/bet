# 데이터 확보 상태

2026-10-28 KST에 현재 클라우드 환경에서 아래 공식 주소에 HTTPS HEAD 요청을 했습니다. 모두 프록시 CONNECT 단계에서 HTTP 403으로 차단되었습니다. 이는 공급원 자체의 장애나 계정 권한 부족을 입증하지 않습니다. 접근 제한을 우회하지 않았으며 최신 이용 약관·지원 리그·가격·요청 한도는 **확인하지 못했습니다**.

| 출처 | 확인을 시도한 주소 | 이번 버전 연결 |
| --- | --- | --- |
| 베트맨 공식 사이트 | https://www.betman.co.kr | 없음. 공개 API 제공·자동 수집 허용 여부 미확인 |
| football-data.org 공식 개발 문서 | https://www.football-data.org/documentation/quickstart | 없음. 경기/팀 데이터의 후보이며 베트맨 상품·배당 공급을 보장하지 않음 |
| football-data.org 등록 안내 | https://www.football-data.org/client/register | 가입·결제 안 함. 최신 무료/유료 범위·비용·제한 미확인 |

지금 실제로 사용할 수 있는 입력 경로는 직접 입력, UTF-8 CSV 업로드, CSV 붙여넣기입니다. 예시 데이터는 자체 생성한 가상 경기입니다. 실제 경기·선수·뉴스·배당·날씨 자료를 확보했다는 뜻이 아닙니다.

향후 연결 순서:

1. 공식 문서의 접근이 가능한 환경에서 라이선스, 재배포/캐싱 허용, 배당 이용 권한과 지원 상품, 요금·쿼터를 확인합니다.
2. 이용 가능한 공급원과 연결할 항목을 고르고 비용·제한을 사용자에게 설명합니다. 유료 가입·결제는 사용자 승인 후 진행합니다.
3. 키가 필요한 경우 운영체제 환경변수에서 읽는 공급원 어댑터를 추가합니다. 키를 CSV·코드·Git·화면에 넣지 않습니다. 현재 버전은 API 호출이나 키가 필요하지 않습니다.
4. 공급원의 UTC 시각을 시간대 포함으로 보존하고 화면에는 KST로 표시합니다. 출처/수집/정보 기준 시각을 보존합니다.
5. 응답 형식·누락·지연·오류·실제 상품 대응 관계를 테스트한 뒤 연결됨으로 표시합니다.
6. 실시간은 별도 피드와 관측 시각 검증·스코어/퇴장 처리 모형이 준비된 후 추가합니다. 현재 수동 상황 계산과는 구별합니다.

공식 문서 접근 정책이 바뀌어야 할 경우 위 호스트의 환경 설정 허용 여부를 검토할 수 있습니다. 첫 버전 실행에는 이 변경이나 API 키가 필요하지 않습니다. 스크린샷 인식은 구현하지 않았습니다.
