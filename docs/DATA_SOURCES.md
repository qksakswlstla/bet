# 다섯 대회 공식 자료 접근 조사

2026-10-28 KST, 아래 주소에 실제 HTTPS GET 요청을 수행했습니다. 모두 현재 환경의 프록시 CONNECT 단계에서 HTTP 403이 반환되었습니다. 접근 제한을 우회하지 않았습니다. 이는 해당 공식 사이트가 일반 사용자에게 차단되었다는 뜻은 아닙니다.

| 사용자 지정 대상 | 조사 주소 | 결과 | 최신 시즌·정확한 공식 대회명·단계·규정 | 이용 조건·API·갱신 주기 |

위 URL의 최신 경로 유효성이나 페이지 내용을 확인했다는 뜻은 아닙니다. 화면의 대회명은 사용자가 지정한 이름이며 공식 시즌 명칭을 검증했다는 뜻이 아닙니다. 유료 API 요금·제한도 확인하지 못했으며 가입·결제하지 않았습니다.

현재 실제 이용 가능한 경로는 사용자가 이용 권한을 가진 자료의 수동 입력·CSV입니다. 모형 입력 근거와 시즌·단계·공식 경기 규정·베트맨 정산 범위를 사용자가 직접 확인하여 출처와 시각을 기록합니다. 미확보 항목은 빈칸으로 두고 확률을 보류할 수 있습니다.

조사 결과 어느 대회도 실제 학습 자료를 확보하지 못했습니다. 따라서 실제 데이터 가용성의 우열을 지어내지 않고, 기존 모형 재사용과 구조 검증 가능성을 기준으로 다음 구현 순서를 선택했습니다.

1. 대회/부문/시즌/상품 식별자, 입력 검수·보류 상태.
2. 기존 축구 모형을 J리그컵·AFC 챔피언스리그 엘리트의 90분 조건부 계산으로 제한.
3. KBL·NBA에 공통 속도와 전반 점수 차 조건이 있는 농구 모형 추가.
4. KOVO 남녀부 각각의 수치로 랠리→세트→경기 구조 계산.
5. 대회 혼합 조합에서 동일 경기 중복 제외, 세부 집단별 기록·평가.

다음 실제 데이터 연결에는 환경의 위 호스트 접근 허용 및 공식 이용 조건 확인이 필요합니다. 네트워크 설정을 바꾸거나 유료 서비스를 결제하지 않았습니다. 자동 수집·실시간 분석은 미연결 상태입니다.

후속 자동 조회 구현에서는 API-Sports/API-Football/The Odds API를 조사하고 키 기반 후보 어댑터를 추가했습니다. 최신 조사·가격 미확인·연결 제한과 검증 수준은 [자동 조회 안내](AUTOMATIC_DATA.md)를 참고하세요.
